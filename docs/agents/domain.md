# Domain Docs

## 布局

本仓库采用 single-context：

- GLOSSARY.md：根目录的统一领域术语表。
- docs/adr/：架构决策记录，采用 0001-简短主题.md 的编号形式。

## 探索代码前

读取 GLOSSARY.md，以及 docs/adr/ 中与当前任务相关的决策。

文件尚不存在时，静默继续，不主动要求补建。
domain-modeling 技能会在术语或决策明确后按需创建这些文件。

## 使用领域术语

issue 标题、重构建议、假设和测试名称中的领域概念，
使用 GLOSSARY.md 定义的术语，遵守其中对同义词的约定。

需要的概念尚未收录时，先判断是否引入了项目不使用的语言；
确有缺口时，记录为 domain-modeling 的后续输入。

## 决策冲突

建议与现有 ADR 冲突时，明确指出对应 ADR、冲突内容及重新考虑的理由。
